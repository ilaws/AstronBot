## Hello! This is my AstronBot.
This is a simple slack bot that assists with basic NASA-related commands. It uses the NASA API and currently only works with APOD and EPIC API calls.
## Commands
/astronbot-ping: Tells the user the ping of the bot
/astronbot-apod: Gives the user the Astronomy Photo of the Day
/astronbot-epic: Shows the user a recent photo of our planet!
/astronbot-help: Self explanitory!
## About the project
My biggest challenge with this project was interfacing the API's into the slackbot. Being able to do this is something that I am most proud of, also
## Replicate on your machine!
Edit the .env file to contain your API keys, and you should be all good to go!
